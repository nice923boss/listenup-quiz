# ListenUp Quiz

英文聽力測驗播放器。老師在網頁上手動輸入考卷題目，設定每題重複幾遍、間隔幾秒，APP 用電腦內建的語音照順序把整份考卷念出來。

- 純網頁，不需要安裝、不需要登入，資料只存在老師自己的瀏覽器
- 支援 Windows 上的 Chrome 與 Edge
- 題目可以中英穿插：英文用英文語音念，中文字用中文語音念
- 「看圖對話」題型每題可以加一張圖片，播放時先顯示圖片，再念對話
- 題目與設定可以「下載專案」存成資料夾，到別的教室用「載入資料夾」讀回

> 目前狀態：程式已完成，聲音、間隔、教室電腦、投影機等項目還沒有人工驗收，見 [`docs/acceptance-checklist.md`](docs/acceptance-checklist.md) 與文末「已知限制」。

---

## 開啟方式

二擇一：

1. **本機**：在 APP 資料夾雙擊 `index.html`，用 Chrome 或 Edge 開啟。不需要網路（字型除外，見「離線使用」）。
2. **網址**：開啟 <https://nice923boss.github.io/listenup-quiz/>。

第一次開啟會出現操作導覽；之後可以在「設定」頁按「重看導覽」。

## 老師操作流程

### 1. 輸入題目（「題目」頁）

1. 最上方輸入考卷標題（只顯示，不會念出來；也是下載專案的資料夾名稱）。
2. 按「新增大題」，每個大題填：
   - **代號**：A、B、C…，播放時念成 `Part A.`
   - **題型**：見下表
   - **英文標題**：例如 `Listen and Write the Number`
   - **中文說明**：例如「仔細聽，把正確的號碼寫在單字下方」
   - **題目內容**：照下表格式打字或貼上，文字框裡的灰字就是範例
3. 右側「解析結果」即時列出題號與內容。格式不對的行會標紅並寫出原因，要改好才能儲存、播放、下載。
4. 大題可以用左邊的握把拖曳排序，也可以收合、刪除。
5. 某個大題要用不同的節奏（例如短文想多停幾秒），打開「本大題設定覆寫（留空＝沿用全域）」填重複次數、同題重複間隔、下一題間隔。

| 題型 | 輸入規則 | 範例 |
|------|---------|------|
| 單字 | 一行一題 | `that` |
| 發音字母 | 一行一題，用 `[ ]` 標出底線字母；畫面顯示底線，念的時候去掉括號 | `[d]og` |
| 對話 | 每行 `A:` 或 `B:` 開頭（半形、全形冒號都可以），空一行分隔不同題；同一行 `A：… B：…` 會自動拆成兩句；A、B 不會念出來 | `A: What's wrong?`<br>`B: Ouch! My foot hurts.` |
| 看圖對話 | 打字方式和「對話」相同；每題可以再加一張圖片（見下方「看圖對話的圖片」） | 同對話 |
| 句子 | 一行一題 | `Can you give me a hand?` |
| 短文 | 整篇貼上算一題，播放時自動切成句子 | `Today is Saturday. It's sunny and hot. ...` |

**看圖對話的圖片**

- 「對話」題型照舊；考卷上有圖的大題，題型改選「看圖對話」。
- 打好對話後，右側解析結果每一題旁邊有「加圖片」，選一張圖片檔（JPG、PNG 等瀏覽器能開的格式）。已有圖片時按「換圖片」替換，按「✕」移除。
- 標題旁顯示「圖片 1 / 4」這類數字，表示 4 題中有 1 題已加圖片。沒加圖片也能儲存、播放，那一題播放時就不顯示圖片。
- 圖片綁在「第幾題」：在中間插入或刪除一題時，圖片留在原本的題號，不會跟著對話移動，改完要重新檢查一次。
- 圖片會自動縮小（長邊 1024 像素）並存成 JPG，和題目一起存在瀏覽器與 `exam.json`。瀏覽器儲存空間約 5 MB，能放幾張依圖片內容而定（還沒實測上限）；滿了會出現「瀏覽器儲存空間已滿，無法儲存。」，請刪掉不用的大題或圖片。

6. 按「儲存」存到這個瀏覽器。有沒存的變更時，上方會出現「有未儲存的變更」；這時關分頁，瀏覽器會先問你。
7. 要出新的一份考卷，按「儲存」左邊的「清空題目」，確認後清掉考卷標題與所有大題（設定保留）。清空後要按「儲存」才會覆蓋瀏覽器裡存的舊題目；還沒儲存前重新整理頁面，舊題目會回來。

### 2. 設定語音與節奏（「設定」頁）

**語音**

- 語音區最上面列出這台電腦偵測到幾個英文、中文語音。
- 分別選「英文語音」「對話 B 角語音」「中文語音」，旁邊按「試聽」。
  - 對話 B 角要選一個和英文語音不同的聲音，學生才聽得出兩個人。預設是「與英文語音相同」。
  - 「中英穿插試聽」可以輸入自己的句子，看看哪些字會用哪個語音念。
- 下拉選單分兩組：「本機語音（離線可用）」與「線上語音（需要網路）」。上課地點網路不穩，建議選本機語音。
- 線上語音念不出來時（例如斷網），APP 會自動改用本機語音並跳出提示。
- 換到另一台電腦時，如果原本選的語音那台沒有，會改用同語言的第一個語音並提示「原設定語音「…」在這台電腦不存在，已改用「…」。」

**電腦沒有英文語音或只有 1 個時**

到 Windows「設定 > 時間與語言 > 語音」，在「管理語音」按「新增語音」，加裝英文（美國或英國）語音；要念中文就加裝中文（台灣）。裝好後回到 APP 按「重新偵測」。

- 完全沒有英文語音：「播放」按鈕停用，設定頁說明原因。
- 只有 1 個英文語音：設定頁提醒對話的 A、B 角會是同一個聲音。

**節奏**（預設值）

| 設定 | 預設 | 範圍 |
|------|------|------|
| 語速 | 0.85 倍 | 0.5～1.5 |
| 每題重複次數 | 2 遍 | 1～5 |
| 同題重複間隔 | 3 秒 | 0～60 秒 |
| 下一題間隔 | 6 秒 | 0～60 秒 |
| 大題間隔 | 10 秒 | 0～60 秒 |
| 題號後停頓 | 0.8 秒 | 0～60 秒 |
| 大題標題後停頓 | 1.5 秒 | 0～60 秒 |
| 對話句間停頓 | 0.8 秒 | 0～60 秒 |
| 短文句間停頓 | 0.4 秒 | 0～60 秒 |
| 看圖時間（看圖對話） | 5 秒 | 0～60 秒 |
| 作答時間（看圖對話） | 10 秒 | 0～60 秒 |

「看圖對話」大題用「看圖時間」取代題號後停頓，用「作答時間」取代下一題間隔；大題設定覆寫填了「下一題間隔」時，以覆寫為準。

秒數可以填到小數點後 1 位；設成 0 就不停。另外可以設定：念不念題號（`Number 1.`，每個大題從 1 起算）、大題標題念法（不念／只念英文／英文＋中文）、播放時顯示題目文字（投影時建議關閉）、播放畫面動態背景、介面主題（亮色／暗色／跟隨系統）。

### 3. 播放

按「播放」進入播放畫面，從頭念到尾。念的順序：

1. 大題開頭念 `Part A. Listen and Write the Number`，停頓
2. 每題念 `Number 1.`，停頓，念題目，等「同題重複間隔」，再念一遍
3. 題與題之間等「下一題間隔」，大題與大題之間等「大題間隔」
4. 「看圖對話」大題：念 `Number 1.` 後顯示圖片，倒數「看圖時間」（畫面寫「秒後念題目，請先看圖」），再念對話；題與題之間等「作答時間」
5. 全部念完顯示「播放結束」

畫面上有超大題號、第幾遍、間隔倒數與整體進度；有圖片的題目，圖片在左邊，題號與倒數在右邊（視窗窄時改成上下排列）。建議按 F11 全螢幕投影。

| 操作 | 方式 |
|------|------|
| 播放／暫停 | 空白鍵，或中間的大按鈕。暫停後繼續，會從剛才那句的開頭重念 |
| 上一題／下一題 | 下方按鈕；暫停時跳題不會出聲 |
| 從某一題開始 | 右上角「題目清單」，點那一題 |
| 停止 | 下方方形按鈕，回到第一題 |
| 回到編輯 | 左上角箭頭 |

**播放時請把 APP 分頁留在前景。** 切到其他分頁時，瀏覽器會延後計時，間隔可能變長；APP 會在分頁標題與畫面上顯示警告。播放中 APP 會要求螢幕不要休眠（瀏覽器不支援時略過）。

### 4. 下載專案與載入資料夾

資料存在「這個瀏覽器」：換瀏覽器、換電腦、清除瀏覽資料，或從本機檔案改用網址開啟，都看不到原本的題目。要帶走就用「下載專案」。

**下載專案**

1. 按「下載專案」，選一個存放位置（例如隨身碟）。
2. APP 會在那裡建立 `<考卷標題>` 資料夾，裡面有 `exam.json`（題目）與 `settings.json`（設定）。同名資料夾已存在時會先問要不要覆蓋。
3. 如果瀏覽器不能直接寫入資料夾，會改成下載 `<考卷標題>.zip`，請解壓縮後保存。

**載入資料夾**

1. 按「載入資料夾」，選剛才下載的 `<考卷標題>` 資料夾（選它的上一層也可以，APP 會找底下第一個有 `exam.json` 的資料夾）。
2. 載入成功後，目前的題目與設定會換成資料夾裡的內容，並存進這個瀏覽器。
3. 檔案有問題時會列出哪個檔案、哪個欄位、什麼原因，目前的資料不會變動。
4. 資料夾裡沒有 `settings.json` 時，設定改用預設值。

`samples/g5-114-2-mid1` 是一份範例考卷，可以直接載入試用。

## 離線使用

把整個 APP 資料夾（至少要有 `index.html`、`css`、`js`、`vendor`）複製到隨身碟或教室電腦，雙擊 `index.html` 即可。

- 編輯、播放、下載、載入都不需要網路。
- 字型（Lexend、Noto Sans TC）從網路載入；離線時改用電腦內建字型，版面不變，字的樣子略有不同。
- 線上語音離線不能用，請選「本機語音（離線可用）」。

## 部署到 GitHub Pages（網頁上傳，不需要 git 指令）

需要一個 GitHub 帳號。免費方案的 GitHub Pages 只能用在公開（Public）的儲存庫，題目資料不會上傳（只存在各自的瀏覽器），上傳的只有程式。

1. 登入 GitHub，右上角「+」→「New repository」。
2. Repository name 填 `listenup-quiz`，選「Public」，按「Create repository」。
3. 在新儲存庫的頁面點「uploading an existing file」（已經有檔案的儲存庫則是「Add file」→「Upload files」）。
4. 打開電腦上的 APP 資料夾，把下面 4 項一起拖進網頁：
   - `index.html`
   - `css` 資料夾
   - `js` 資料夾
   - `vendor` 資料夾
   - （可選）`README.md`

   共 34 個檔案（不含 README），每個都小於 1 MB，在 GitHub 網頁上傳的限制內（一次最多 100 個檔案、每個檔案最大 25 MB）。其他資料夾（`docs`、`spike`、`tests`、`mockups`、`samples`）是開發用，不用上傳。
5. 等檔案列表跑完，下方按「Commit changes」。
6. 到儲存庫上方的「Settings」→ 左側「Pages」。
7. 「Build and deployment」的 Source 選「Deploy from a branch」，Branch 選 `main`，資料夾選 `/ (root)`，按「Save」。
8. 等 1～5 分鐘，重新整理 Pages 設定頁，上方會出現網址：<https://nice923boss.github.io/listenup-quiz/>。
9. 用 Chrome 或 Edge 開啟網址確認可以使用。

之後要更新程式：重複第 3～5 步上傳新檔案（同名檔案會被取代），GitHub 會自動重新部署。

## 測試（給維護者）

需要 Node.js（開發時用 v24）。

**單元測試**（parser、schema、timeline、speech、player、storage）：

```bash
node --test "tests/*.test.js"
```

**瀏覽器 UI stub 測試**：用 Playwright 開 Chrome 與 Edge，把 `speechSynthesis` 和資料夾選擇換成假的（立即念完、假資料夾），檢查畫面流程與播放順序。這是 stub 測試，不是端對端測試：沒有真的發出聲音，也沒有真的開資料夾對話框。需要先安裝 Playwright，並把 `NODE_PATH` 指到它的 `node_modules`：

```bash
node tests/ui-stub.run.js all
```

（參數可以是 `chrome`、`msedge` 或 `all`。）

**真瀏覽器測試**：用 Playwright 開這台電腦真的 Chrome 或 Edge，以 `file://` 開啟 APP、用電腦內建語音念，只加監聽記錄語音事件、間隔時間與防止休眠的結果，不替換任何東西。沒有人聽聲音，也不開資料夾對話框，所以仍要人工驗收。結果存在 `tests/results/real-<瀏覽器>-<模式>.json`。

```bash
node tests/real-browser.run.js chrome full
```

（第 1 個參數是 `chrome` 或 `msedge`；第 2 個是 `full` 整份範例考卷約 8 分鐘、`controls` 暫停／跳題／背景分頁、`offline` 模擬斷網、`preview` 設定頁試聽。）

**比對兩個專案資料夾**（人工驗收用，忽略排版只比內容）：

```bash
node tests/compare-project.js "<資料夾 A>" "<資料夾 B>"
```

## 已知限制

以下項目登記在 [`GAPS.md`](GAPS.md)，括號是編號。

**尚未人工驗收**

- 聲音實際聽起來如何、碼錶量到的間隔是否在 ±0.5 秒內、對話 A/B 聽不聽得出兩個人，都還沒有人確認（G001）。自動化只驗證到事件時間。
- 只在開發機（Windows 11、Chrome、Edge）測過，教室電腦的語音清單與音效設定可能不同（G002）。
- 實際斷網只用代理模擬過，關 Wi-Fi 時線上語音的反應可能不同（G007）。
- `file://` 開啟時「下載專案」寫入資料夾還沒實際操作過；寫不進去時會改下載 zip（G006）。
- 真的語音只在開發機的 Chrome、Edge 自動跑過，記錄語音事件與時間，沒有人聽（G012 已補，聽感見 G001）。真實的資料夾對話框沒有操作過（G013）；防止螢幕休眠只確認到瀏覽器核准，螢幕是否真的保持亮著還沒確認（G014）。
- 「看圖對話」只用假語音的 stub 測試與截圖檢查過版面；真的語音播放、投影機上圖片看不看得清楚、縮小後的 JPG 畫質，都還沒有人確認（G015）。

**使用上的限制**

- 播放分頁切到背景時，Chrome 曾量到間隔多約 1 秒（G003）；用正式播放流程在背景約 26 秒重測沒有重現，但原因還沒確認；長時間在背景的影響還沒測（G005）。請把分頁留在前景。
- Edge 視窗最小化時，瀏覽器仍回報頁面可見，所以不會出現背景警告（G004）。
- 暫停後按繼續，會從目前這句的開頭重念，不是從中斷的字接著念（G010）。
- 長句念到一半沒聲音的瀏覽器問題這次沒有重現，但樣本少；若發生，APP 的看門狗會在時限後跳到下一步（G008）。
- 中英穿插的切段已用測試涵蓋 `Mr.`、`3.5`、`a.m.`、`4D`、全形英數、「」與數字等情況，但還沒用老師的實際題目試聽；切錯時會變成中文語音念英文字（G009）。
- 間隔從語音念完開始計時，瀏覽器開始發聲前的延遲（最多約 0.13 秒）沒有扣除。
- 圖片存在瀏覽器（約 5 MB）與 `exam.json`，能放幾張還沒實測（G016）。
- 圖片綁在題號：中間插入或刪除題目時，圖片不會跟著對話移動（G017）。
- Chrome、Edge 以外的瀏覽器沒有測試。這類瀏覽器「載入資料夾」若在選擇視窗按取消，畫面可能沒有反應，資料不受影響（G013）。
